# Доработки после Selectel MVP

Ничего ниже не выдаётся за реализованную возможность. Production rollout —
отдельный этап после приёмки MVP на тестовом.

| Приоритет | Работа | Условие готовности |
|---|---|---|
| Следующий | Расписание аккаунта и история запусков | Периодический сбор, backoff, восстановление после перезапуска, одно выполнение на аккаунт |
| Следующий | План создания/сопоставления в UI | Пообъектный просмотр действий Guard, явное применение, защита от дублей и устаревшего плана |
| Следующий | Обновление native IPAM из аккаунта | Показ плана и согласованное обновление Prefix/IP/VLAN без изменения management IP и pfSense |
| Следующий | Читаемые ошибки и проверка доступа до сбора | Разделить неверный пароль, отказ продукта, недоступность NetBox и неизвестный результат импорта |
| Следующий | Улучшение интерфейса ресурсов | Единый стиль NetBox, поиск/фильтры, состояния пустого списка, отсутствие JSON в пользовательских карточках |
| Следующий | Доступ команд к аккаунтам | Account-scoped RBAC, без утечки DNS и проектов другим командам |
| Далее | Аппаратные идентификаторы Selectel | Подтверждённый API serial/system UUID; default и sample serial исключены |
| Далее | Proxmox DMI | Отдельно согласованный канал; API-only не обещает DMI |
| Далее | NIC ↔ порт провайдера | Достоверные MAC/LLDP/CDP/идентификаторы стороны Selectel; без привязок по догадке |
| Далее | Kubernetes и managed databases | Отдельные адаптеры API, покрытие/права, устойчивые ключи, UI; не поддерживаются автоматически только из каталога |
| Далее | Другие услуги и native сети/диски/LB | Зафиксированная модель для каждой услуги, сохранение родительских связей и областей проекта/региона |
| Далее | Полнота S3 | Проверенные S3 API для lifecycle/versioning/policy; не читать содержимое объектов |
| Далее | Ротация и отключение подключения | Проверка новых секретов, отзыв служебного токена, явное отключение без удаления инвентаря |
| Далее | Большие аккаунты | Пакетный импорт, ограничение истории, прогресс по категориям, проверка лимитов и пагинации |

Отдельный поток pfSense: выяснить состав трёх найденных VM (сейчас список строится
по имени), затем дорабатывать подключение/сбор и UI. Не считать каждую найденную
VM подключённым pfSense и не менять её настройки в рамках Selectel MVP.
