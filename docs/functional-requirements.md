# Оставшиеся доработки и приёмка NetBox Sync

Обновлено 7 октября 2026. Реализованные требования вынесены в [историю 7 октября](requirements-history-2026-10-07.md) и [историю 6 октября](requirements-history-2026-10-06.md). Локальная реализация не означает развёртывание.

## Приёмка текущего обновления

- **REQ-013 — сети:** открыть LAN2 / 10.24.2.0/24; пустой поиск и фильтры сохраняют только LAN2. Поиск 10.24.1.20 показывает подсказку и ссылку на LAN1 без перехода. Проверить свой IP и IP вне известных сетей. Общих ссылок «Все сети» и «Открыть сети и занятость адресов» больше нет; индивидуальные ссылки сохранены.
- **REQ-012 — pfSense:** проверить отдельную вкладку фактических маршрутов/PF/NAT, четыре вложенные вкладки и последнюю вкладку пакетов. Отдельная верхняя таблица «Сеть pfSense» убрана. Проверить Firewall INTERLAN при 100% и 90%, обе темы и узкий экран: значения не дробятся, широкая таблица прокручивается.
- **REQ-011 — массовые действия:** проверить компактную колонку выбора, имена без повторов, выпадающий список интервалов. Удаление показывает имя/готовность/число объектов и требует точного имени каждого источника. Фактическое массовое удаление отложено; отдельно проверить запрет при активной синхронизации на выделенном тестовом источнике.
- **PF/NAT:** повторить «Подключить и собрать» для обновления удалённого сборщика. Проверить PF/NAT сразу, после двух минут и после перезагрузки pfSense. Непривилегированный аккаунт не получает sudo или запись в /dev/pf. Обновление одного Guard недостаточно. [Описание механизма](../deploy/pfsense/README.md).
- **Production:** после отдельного обновления проверить кнопки Connection и вкладки. Старый production-дефект кликов не объявляется устранённым по тестовой установке.

## Подтверждено пользователем на тестовой установке

MAC crm-bpm обновлён; синхронизация Proxmox и ESXi завершилась успешно, повторный план без изменений. Диски VM, связи с хостом, перенос описания, основной сетевой функционал, вложенные вкладки pfSense и кнопки Connection работают. Массовые расписания и запуск автоматической синхронизации подтверждены. Новые изменения интерфейса из текущего прохода требуют отдельной приёмки выше.

## Отложено

- **REQ-001:** новый ESXi/Proxmox с отсутствующими справочниками — нужен подходящий хост.
- **REQ-007:** фактические Weekly/Monthly и сохранность расписания после перезапуска службы Sync.
- Резервирование IP — отложено; существующие данные сохранены.
- **Блок «Гипервизор и виртуальные машины»:** оставить без изменений до обсуждения. Device отражает конкретный хост, Cluster — логическую группу. Связи для Map и необходимость таблицы — отдельные решения.

## REQ-010 — NetBox Map, исключён из текущего прохода

- Подтверждение общей сети между разными гипервизорами по явным данным инфраструктуры.
- Вложенные PF anchors и содержимое динамических таблиц.
- Анализ пути, порядка firewall/NAT, расписаний и сценария внутри LAN без pfSense.
- Map и сравнение сценариев без изменения инфраструктуры.

См. [архитектурное решение](netbox-map-decisions.md). Эти функции не объявляются выполненными.
