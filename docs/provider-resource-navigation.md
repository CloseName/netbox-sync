# Реестр ресурсов провайдеров

В левом меню NetBox: **NetBox Sync → Ресурсы провайдеров**.
Для просмотра нужно право `netbox_guard.view_resourceregistry`: оно открывает
все импортированные аккаунты, как и прежняя страница реестра.

Внутри страницы: **Selectel → аккаунт → проект → категория → ресурс**.
Проекты определяются по ID провайдера, а не по имени. Категории появляются
из сохранённых данных: выделенные и облачные серверы, DNS-зоны и записи,
бакеты S3/Swift и домены бакетов. Для неизвестного проекта отображается его
ID, для отсутствующего — отдельная группа «Без проекта / уровень аккаунта».
Поиск и пагинация действуют внутри выбранного проекта и категории.

Серверы читаются из ProviderInventory, DNS/S3 — из ProviderResourceRegistry.
Это представление не создаёт и не перепривязывает устройства, IP, интерфейсы
или виртуальные машины. Времена наблюдения у источников могут различаться.
Снимок сервера не считается доказательством его текущей доступности.

История DNS/S3 показывает только соответствующую сохранённую ревизию;
текущие серверы не добавляются в исторический снимок. Отсутствующие в последнем
сборе DNS/S3-ресурсы остаются видимыми с отметкой о сохранённых прежних данных.

Отсутствующая категория означает, что в локальном реестре нет таких записей,
а не подтверждённое отсутствие услуги в Selectel. Новые виды услуг требуют
сборщика и проверяемого контракта импорта; меню не делает их автоматически
поддерживаемыми. Дерево не содержит привязок к конкретным серверам или аккаунтам.
